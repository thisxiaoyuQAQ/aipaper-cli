# 18-暂停退出与安全恢复

## 模块概述

实现 TUI 中断和恢复体验：写作中 Ctrl+C 请求 runtime 安全停止并保存 checkpoint；下次启动可继续；表单和确认页退出需确认，重新开始需二次确认。

## 接口与类型定义

恢复入口：

```go

```

暂停相关 RuntimeEvent：

```go
EventCheckpointSaved RuntimeEventKind = "checkpoint_saved"
EventRuntimeDone     RuntimeEventKind = "runtime_done"
EventRuntimeError    RuntimeEventKind = "runtime_error"
```

## 实现要求

- 写作中 Ctrl+C 不直接强杀进程，而是请求 runtime 在安全点停止。
- 停止成功后展示“进度已保存，下次启动可继续”。
- 若 runtime 已保存 checkpoint，展示 step 和 checkpoint 路径。
- 下次启动 valid checkpoint 时显示恢复提示：继续写作、重新开始、退出。
- 继续写作调用 `app.Recover` 并把 recovery prompt 注入 runtime。
- 重新开始必须二次确认；不得未确认删除、清空、覆盖既有 run 产物。
- 表单页、确认页、配置页 Ctrl+C 显示退出确认；未保存改动需提示。
- 退出时尽量恢复终端状态。

## 测试要求

- WritingProgress 收到 Ctrl+C 后进入 stopping 状态并调用 stop request。
- checkpoint saved 后展示可恢复提示。
- valid checkpoint 下次启动进入 RecoverPrompt。
- 重新开始需要二次确认；未确认不会删除任何文件。
- 表单页有未保存改动时 Ctrl+C 显示确认。

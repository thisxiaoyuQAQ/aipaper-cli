## 接口与类型

- 输入：outline、accepted chapter drafts、confirmed references、chapter reviews。
- 输出：`final/paper.md`、`final/paper.docx`、`final/references.md`、`final/citation-trace.json`、`final/report.md`。
- Docx 导出失败返回 `EXPORT_DOCX_FAILED`，不阻塞 Markdown 和 report 输出。
- 已落地 API：`internal/export.LoadInput`、`ExportFinal`、`SimpleDocxExporter`、`DocxExporterFunc`。

## 实现要点

- Markdown 是首要交付物，Docx 是可交付初稿，不承诺高级排版。
- `citation-trace.json` 必须记录章节、段落、claim、reference key、来源类型、Editor 是否验证、是否需人工复核。
- `report.md` 汇总质量评分、unsupported claims、needs_human_review 章节、导出失败或引用格式化问题。
- 引用格式化失败不阻塞正文生成，但必须进入报告。
- 导出工具可重复执行：final 固定文件覆盖写入，trace/report 记录 `export-YYYYMMDDTHHMMSSZ` 版本；Docx 失败时清理旧 `paper.docx`。

## 测试要点

- 使用小型 accepted drafts fixture 汇总 Markdown。
- confirmed references 能导出 references.md 和 confirmed.bib 复用。
- Docx exporter mock 失败时仍生成 report。
- citation trace 中不得出现未确认 reference key。

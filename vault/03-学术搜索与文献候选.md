# 03-学术搜索与文献候选

## 模块做啥（1 行）

根据写作需求调用学术搜索源，标准化候选文献，去重后写入候选文献文件。

## 依赖谁（1 行）

- 可并行：vault/02-材料解析与索引.md

## 需要先读哪几个文件（2~5 个）

- 项目备忘录.md

## 接口与类型

- 输入：`Requirements` 中的 topic、research_questions、scope、language、allow_online_search、search_providers。
- 输出：`ReferenceCandidates{Items []ReferenceCandidate}`。
- 候选字段：title、authors、year、source、doi、url、abstract、venue、citation_count、relevance_score、relevance_reason、dedupe_group、status。

## 实现要点

- 内置免费源：Semantic Scholar、Crossref、arXiv、PubMed。
- 可选增强源：SerpAPI、Tavily、Exa、Google Scholar 代理、自定义 provider。
- 查询由 Coordinator 决策，search tool 只执行并返回事实 JSON。
- 标准化字段时保留 source 和原始 URL/DOI。
- 去重顺序：DOI 优先，URL 次之，title + author + year hash 兜底。
- 搜索超时、限流、空结果需要结构化错误或结构化空结果，不 panic。

## 测试要点

- provider 使用 HTTP mock，不依赖真实网络。
- 覆盖超时、限流、字段缺失、空结果。
- 去重测试覆盖 DOI、URL、title hash 三层。
- 相关性分数缺失时保持字段可省略，不编造高分。
